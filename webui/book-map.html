对照 · 第 1 站

两个公式，同一个命题

书的核心公式和本教程的配方公式，是同一命题的两种展开——而且两边对「什么最值钱」的判断完全一致：模型之外的工程（Harness）才是竞争力。

书 · 第 1 章
Agent = LLM + 上下文 + 工具　（＋Harness 工程 = 模型之外的一切竞争力）
本教程 · 进阶篇
领域 Agent = 循环(不变) × 提示词 × 工具集 × 上下文策略 × 守卫 × 评测
书把「上下文 + 工具」两个名词展开成十章原理（ch2 上下文、ch3 记忆、ch4 工具、ch6 评估…）；教程把「循环 × 守卫 × 评测」落成三份真代码和 M0–M11 施工图。书回答「为什么这样设计」，教程回答「设计落到第几行代码」——合起来正好一张完整地图。分界线也清晰：书的 ch7（后训练）跨进了模型侧，那是 harness 侧教程（本站）刻意止步的地方——这条界线本身就是一课。

怎么配合用 · 第 3 站

三种读法，按你的性格挑

① 动手派（推荐默认）

  1. 教程 mini M0–M3（先让循环转起来）
  2. 书 ch1/ch2（回头补"为什么"）
  3. 教程 M4–M7（工具 + 会话）
  4. 书 ch4/ch6（工具分类学 + 评估学）
  5. 教程 M10 评测 → 书 ch10 → 进阶篇 A2

② 通读派

书从引言到 ch10 通读一遍（一晚一章，两周）；然后回到教程，按上面映射表逐章"看真代码怎么落地"——ch5 配 tau 源码、ch6 配 rust 评测页、ch10 配编排模式动画。

③ 按病抓药

把映射表当索引用：
· 上下文总爆 → 书 ch2 + 蓝图 L4
· 工具设计纠结 → 书 ch4 + 文档 §4.3
· 不知道好不好 → 书 ch6 + rust 评测页
· 想上多 agent → 先冷水框再书 ch10

元彩蛋 · 第 4 站

这本书本身就是一个 agent 使用示范

仓库里有个 cursor-chats/ 目录：269 段作者与 AI 结对写书、写实验代码的真实对话记录。「用 agent 写一本讲 agent 的书」——这既是书 ch5（代码是元能力）的现身说法，也是进阶篇「操作手册」的高手实况：怎么下任务、怎么贴报错全文、怎么中途纠偏，一段段全是样本。

另有 EXPERIMENT_TRIAGE.md 记录实验分诊（哪些跑通、哪些是反例）——比如「阶段脚手架实测不饱和」这类反例也留在仓库里。诚实的实验记录，和本教程「结论限定在当前快照」是同一种味道。
